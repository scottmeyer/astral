## Repairs included

- Isolated completion fixtures from host Git policy and disabled background Git
  maintenance in fixtures that compare complete repository contents.
- Explicitly released launch ownership locks even when another descriptor still
  references the same open file description; added a regression control.
- Repaired Windows recovery of a journal's incomplete trailing record while
  preserving append semantics for normal writes.
- Reduced repeated Git probes and snapshot loading checks, verified bounded blob
  reads against Git object IDs, and woke Git readers on I/O readiness. The hook's
  three-second deadline, output limits and final observation validation remain
  enforced. Tests cover changes during loading, corrupted objects, oversized
  streams, early pipe closure and lingering subprocess writers.

These checks add no live-provider or cross-account Codex qualification. The
